# bufferclick Portfolio Website

A modern, black and white themed portfolio website with an admin panel for managing projects.

## 🚀 Quick Start

1. **Set up Firebase Rules** (See FIREBASE_SETUP.md)
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. **Access the admin panel:**
   - Go to `/admin`
   - Username: `admin`
   - Password: `bufferclickbutterlick`

## 📱 Pages

- **/** - Home page with your introduction
- **/projects** - Browse all your projects
- **/admin** - Admin login
- **/admin/panel** - Manage your projects

## ✨ Features

### For Visitors:
- Clean black & white design
- View your profile and introduction
- Browse all projects
- Click projects to visit their URLs

### For Admin:
- Secure login system
- Add new projects with:
  - Name
  - Description
  - Image URL
  - Redirect URL
- Reorder projects with up/down arrows
- Delete projects
- Real-time Firebase sync

## 🛠 Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- Firebase Realtime Database

## 🎨 Theme

Minimalist black and white color scheme throughout the entire site.
